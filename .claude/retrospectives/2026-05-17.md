## Recurring gotchas (action required)

Six other crates (pi-rs, prime-rs, fib-rs, sq-rs, twin-primes-rs, e-rs, factorial-rs, perfect-numbers-rs, goldbach-rs, amicable-rs) lack the target. → **Proposed action:** add `mutants` target to all remaining Rust crate Makefiles in a single rollout PR.
- **Coverage drops after `cargo fmt`** (PR #42) — happened once when fmt expanded write! macros. Addressed via `rustfmt.toml` with `use_small_heuristics = "Max"`, but worth checking every crate has this rustfmt.toml. → **Proposed action:** audit all `<crate>-rs/rustfmt.toml` files exist with correct content.
