# ADR 0017: defusedxml for XXE-safe XML parsing in scripts

- **Date:** 2026-05-23
- **Status:** Accepted

## Context

`scripts/test_metrics.py` parsed JUnit XML output from nextest using Python's stdlib `xml.etree.ElementTree`. The stdlib parser is vulnerable to XML External Entity (XXE) injection — a maliciously crafted JUnit XML file could read arbitrary files from the filesystem during parsing.

In CI, JUnit XML is generated by nextest from test output (trusted source). The risk is low in practice. However, using a vulnerable XML parser when a safe drop-in replacement exists is a security smell that `pip-audit` and Snyk flag, and it creates unnecessary exposure if the input source ever changes.

## Decision

Replace `xml.etree.ElementTree` with `defusedxml.ElementTree` in `scripts/test_metrics.py`. defusedxml is a drop-in replacement with the same API that blocks XXE, XEE (XML Entity Expansion / "billion laughs"), and DTD retrieval attacks.

**Known limitation — no type stubs:** defusedxml ships without `py.typed` or `.pyi` stubs. `tree.getroot()` returns an untyped value; pyright infers it as `None`, causing `reportOptionalMemberAccess` errors on every subsequent attribute access.

Fix with a local type annotation at the one call site, keeping stdlib ET for type info only:

```python
import xml.etree.ElementTree as ET              # stdlib — for type annotations only
from defusedxml import ElementTree as _defused_ET  # third-party — for actual parsing

tree = _defused_ET.parse(path)
root: ET.Element = tree.getroot()  # type: ignore[union-attr]
# root is correctly typed as ET.Element for all downstream access
```

This limits suppression to one line rather than adding `reportOptionalMemberAccess: "none"` globally in `pyrightconfig.json`.

**CI dependency:** `factorial-rs.yml` calls `test_metrics.py` but had no Python dependency install step. A pip install step for `defusedxml` (and other script dependencies) must be added to this workflow explicitly.

## Consequences

- XXE vulnerability eliminated from XML parsing in `scripts/test_metrics.py`
- defusedxml added as a script dependency in `install_deps.sh` and `factorial-rs.yml`
- `factorial-rs.yml` gets an explicit Python dep install step
- One `# type: ignore[union-attr]` at `getroot()` — no global pyright suppression needed
- Pattern is reusable: any future script that parses untrusted XML uses this same import split
